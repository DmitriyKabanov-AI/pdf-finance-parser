## 📋 Детальный анализ файлов

### 🐍 `Scripts\generate_html_report.py`

## Назначение

Файл `generate_html_report.py` предназначен для автоматизации процесса анализа финансовых операций и формирования интерактивного HTML-отчета, содержащего детальную финансовую аналитику и визуализации. Отчет генерируется на основе данных из Excel-файла, который содержит финансовые транзакции пользователя.

Отчет включает следующие разделы:
- **Анализ доходов и расходов**: суммарные показатели, структура расходов и доходов, ежемесячный баланс, накопительный баланс, прогноз финансового состояния.
- **Категоризация расходов**: детализированное представление расходов по различным категориям (например, транспорт, продукты, развлечения).
- **Тепловая карта**: визуализация суточных и недельных расходов.
- **Прогноз бюджета**: расчет ожидаемых доходов и расходов на ближайшие месяцы.
- **Информативные подсказки (Insights)**: рекомендации по оптимизации финансов, основанные на анализе отчетных данных.

## Технологии

Для реализации функционала отчета используются следующие библиотеки и технологии:

- **Pandas**: библиотека для обработки и анализа структурированных данных (DataFrames).
- **NumPy**: библиотека для научных вычислений и работы с массивами.
- **JSON**: стандарт представления данных в виде структуры объектов и списков.
- **Regex**: регулярные выражения для поиска ключевых слов и фильтрации строковых данных.
- **Webbrowser**: встроенная библиотека Python для открытия веб-ссылок в браузере.
- **Pathlib**: модуль для работы с путями файлов и каталогов.
- **OpenPyXL**: библиотека для чтения и записи данных из Excel-файлов формата XLSX.
- **HTML шаблоны**: использование готовых HTML-шаблонов для оформления отчета.

## Основные функции и классы

### Ключевые функции:

1. **load_excel(path)**  
   Функция загружает данные из Excel-файла и возвращает DataFrame.
   
2. **normalize_columns(df)**  
   Преобразует имена столбцов в унифицированный вид, заменяя оригинальные названия на стандартные.

3. **parse_dates(df)**  
   Парсит даты и преобразует их в стандартный формат.

4. **parse_amounts(df)**  
   Приводит числовые значения сумм к единому формату и добавляет дополнительные атрибуты (например, абсолютную сумму, признак дохода/расхода).

5. **filter_internal_transfers(df)**  
   Удаляет внутренние банковские переводы из выборки.

6. **categorize(df)**  
   Классифицирует транзакции по заранее заданным категориям (доходы, расходы, штрафы, подписки и др.).

7. **compute_analytics(df)**  
   Выполняет финальный этап анализа данных, формируя итоговую структуру данных для построения отчета.

8. **generate_html(A)**  
   Генерация HTML-отчета на основе подготовленных аналитических данных.

### Ключевые классы:

- **None**

Все необходимые преобразования и расчеты выполняются внутри функций, без выделения отдельных классов.

## Описание работы

### Работа программы пошагово:

1. **Загрузка данных из Excel-файла**  
   Программа считывает данные из указанного Excel-файла (`reports/transactions_consolidated.xlsx`) и создает DataFrame.

2. **Нормализация имен столбцов**  
   Для удобства дальнейшей работы программа переименовывает столбцы согласно внутренним стандартам.

3. **Парсинг дат и чисел**  
   Дата и числовые поля приводятся к нужному типу и форматированию.

4. **Удаление внутренних банковских переводов**  
   Из выборки исключаются транзакции, относящиеся к внутренним банковским операциям.

5. **Классификация транзакций**  
   Каждая транзакция классифицируется по заранее определенным категориям (например, «Транспорт», «Еда», «Развлечения»).

6. **Вычисление аналитических показателей**  
   Рассчитываются общие суммы доходов и расходов, месячные балансы, накопленные расходы, тепловые карты, прогнозы и другие важные показатели.

7. **Генерация HTML-отчета**  
   На основании полученных аналитических данных формируется HTML-отчет, включающий графики, таблицы и информативные подсказки.

8. **Открытие отчета в браузере**  
   После завершения генерации отчет автоматически открывается в браузере.

Программа обеспечивает удобный и наглядный способ анализа личных финансов, позволяя пользователям быстро выявлять слабые места в своем бюджете и принимать обоснованные решения относительно управления финансами.

### 🐍 `Scripts\pdf_final_parser.py`

## Назначение

Файл `pdf_final_parser.py` предназначен для извлечения финансовых транзакций из PDF-документов банковских выписок и консолидации их в единый Excel-файл. Программа автоматически находит файлы формата `.pdf` в специальной директории (`Statements`), извлекает данные транзакций, структурирует их в виде таблицы и сохраняет результат в Excel-таблице.

## Технологии

Используемые библиотеки и технологии:

- **Python**: основной язык программирования.
- **pdfplumber**: библиотека для парсинга текста из PDF-документов.
- **pandas**: библиотека для обработки и анализа табличных данных.
- **pathlib**: модуль для работы с путями файлов и каталогов.

## Основные функции и классы

### Ключевые функции:

- **extract_transactions(pdf_path)**  
Функция извлекает транзакции из одного PDF-документа и возвращает их в виде DataFrame.

- **main()**  
Основная функция программы, запускающая процесс поиска и обработки всех PDF-файлов в директории `Statements`, объединения результатов и сохранения итогового отчета в Excel.

### Классы и объекты:

Не используются явные классы, однако работа ведется с объектами классов `Path` (из модуля `pathlib`) и `DataFrame` (из модуля `pandas`).

## Описание работы

Программа состоит из двух основных частей:

1. **Извлечение транзакций из PDF-документов**
   - Функция `extract_transactions()` открывает PDF-документ, извлекает текст каждой страницы и разбивает его на отдельные строки.
   - Далее программа ищет строки, начинающиеся с даты и содержащие символ рубля («₽»), указывая начало новой транзакции.
   - Для каждой найденной транзакции происходит объединение нескольких строк в одну блок-составляющую, содержащую всю необходимую информацию.
   - Затем используется регулярное выражение для выделения следующих элементов:
     - Даты операции и записи (например, «29.12.2025 29.12.2025»).
     - Суммы операций и списания (например, «-31 571.00 ₽», «-31 571.00 ₽»).
     - Времени проведения операции и записи (если указано).
     - Описания транзакции, включая возможные номера карт.
   - Все эти элементы собираются в словарь, представляющий отдельную транзакцию, который добавляется в список транзакций.

2. **Консолидация и сохранение результатов**
   - В функции `main()` осуществляется поиск всех PDF-файлов в директории `Statements`.
   - Каждый документ обрабатывается функцией `extract_transactions()`, результаты сохраняются в отдельный DataFrame.
   - После завершения обработки всех документов полученные DataFrames объединяются в один общий DataFrame.
   - Итоговый отчет сохраняется в Excel-файле с именем `transactions_consolidated.xlsx` в той же директории.

Таким образом, программа позволяет автоматизировать обработку большого количества банковских выписок, обеспечивая удобный доступ к данным и возможность дальнейшей аналитики.

### 🌐 `Template\dashboard_template.html`

## Анализ HTML-файла `dashboard_template.html`

### Назначение

Этот шаблон предназначен для отображения финансового дашборда, который позволяет анализировать ключевые финансовые показатели, динамику расходов и доходов, выявлять слабые места и предлагать персонализированные рекомендации по оптимизации бюджета.

---

### Используемые технологии

- **HTML**: базовая структура страницы и разметка элементов интерфейса.
- **CSS**: стилизация элементов, оформление цветов, шрифтов и стилей.
- **JavaScript**: динамическое взаимодействие с элементами интерфейса, построение графиков и интерактивных компонентов.
- **Plotly.js**: библиотека для построения интерактивных графиков и диаграмм.
- **Bootstrap**: используется для оформления сетки и адаптивности страниц.

---

### Общая структура шаблона

#### Основные разделы страницы:

1. **Верхняя панель (`header`)**
   - Заголовок сайта («💰 Финансовый Дашборд»).
   - Дата анализа и другие параметры.
   
2. **Контейнер (`container`)**
   - Разделы с ключевыми показателями (KPI).
   - Навигационные вкладки с различными типами аналитики.
   - Графики и таблицы, визуализирующие данные.

3. **Навигация (`tab-nav`)**
   - Вкладки с названиями аналитических разделов («Динамика», «Поведение», «Такси vs метро», «Штрафы», «Время суток», «Категории», «Утечки», «Денежный поток», «Прогноз», «Рекомендации»).

4. **Графики и интерактивные компоненты**
   - Диаграммы и таблицы, показывающие различные аспекты финансовой активности пользователя.

---

### Интерактивные элементы

- **График накопления баланса (`balanceChart`)**
  - Показывает изменение баланса с выделением зон риска.
  
- **Диаграммы динамики доходов и расходов (`monthlyChart`, `burstChart`)**
  - Отображают месячные доходы и расходы, а также средние расходы после получения дохода.
  
- **Тепловая карта расходов (`heatmapChart`)**
  - Представляет распределение расходов по часам суток и дням недели.
  
- **Диаграммы по категориям расходов (`bubbleChart`, `categoryCharts`)**
  - Визуализируют структуру расходов по различным категориям.
  
- **Таблицы штрафов и регулярных подписок (`finesTable`, `subsTable`)**
  - Содержат детализированную информацию о штрафах и регулярных платежах.
  
- **Калькулятор прогноза («Что если»)**
  - Позволяет пользователям моделировать сценарии сокращения расходов и достижения финансовых целей.

---

### Работа с данными

- Данные загружаются через JSON объект (`A`).
- Для каждого графика и интерактивного элемента используются функции рендеринга, такие как `renderBalance`, `renderMonthly`, `renderBurst`, `renderHeatmap`.
- Пользовательские настройки и взаимодействия (например, выбор вкладок, настройка фильтров) обрабатываются через JavaScript-события и функции переключения вкладок (`sw()`).
